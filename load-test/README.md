# 压测说明

1. 先启动 MySQL、Redis、RabbitMQ 和应用，并访问 `/actuator/health`。
2. 预热店铺接口后运行 `shop-cache.js`，记录 QPS、P95、错误率及
   `/actuator/prometheus` 中 `hmdp_cache_*` 指标。
3. 秒杀压测前创建有效时间窗口内的优惠券，并准备多个真实登录 token。
4. 压测后核对三个不变量：数据库库存不小于 0；同一用户同一券最多一单；
   Redis 库存 + 有效预占/订单数等于初始库存。
5. 每次报告都记录 CPU、内存、应用实例数、连接池、消费者并发数、数据量和测试时长。

截图简历中的 `20,000 QPS`、`95% 命中率`、`P95 50ms` 不是项目默认能力，
只有在你的环境中复现并保留报告后才可以使用。
